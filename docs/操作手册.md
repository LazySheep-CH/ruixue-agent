# 操作手册

从 PDF 到可检索知识库的完整流程。每步都是独立、可重跑的脚本(幂等 —— 挂了直接重跑)。

## 前置

```bash
uv sync                                            # 装依赖(含 GPU 版 torch)
cp config/config.example.yaml config/config.yaml   # 配模型,填 $DEEPSEEK_API_KEY
cd docker && cp .env.example .env && docker compose up -d && cd ..   # 起 PG + Milvus
uv run alembic -c ruixue_agent/persistence/migrations/alembic.ini upgrade head  # 建表
```

## 入库流程

| 步骤 | 脚本 | 做什么 | 幂等 |
| --- | --- | --- | --- |
| 1. 整理原始 PDF | `organize_raw.py` | 归类、算 sha256、建 manifest 台账 | ✓ |
| 2. 解析 | `run_mineru_batch.py` | MinerU 批量解析 PDF → 结构化 JSON | ✓(按输出跳过) |
| 3. 过管道 | `run_pipeline.py` | parse→clean→dedup→metadata→quality→chunk,落盘 | ✓ |
| 4. 灌 PostgreSQL | (repository) | Document/Chunk 写入 PG,upsert | ✓ |
| 5. 灌 Milvus | `load_milvus.py` | 子块 embed → 向量库,断点续传 | ✓(已有的跳过) |
| 6. 中文分词 | `backfill_tokens.py` | jieba 分词写入 text_tokens(BM25 用) | ✓(NULL 才做) |
| 7. 建词频表 | `build_term_df.py` | 统计文档频率(BM25 挑词用) | ✓(TRUNCATE 重建) |

关键点:

- **数据从 PG 读,不从 JSON 读** — PG 是 source of truth,JSON 是可删的中间缓存。
- **第 5 步只灌子块** — 父块不做 embedding(Small-to-Big:子块负责被搜到)。
- **改了领域词典后** — 重跑 `backfill_tokens.py --redo` + `build_term_df.py`。

## 检索问答(端到端)

```python
from sqlalchemy.orm import Session
from ruixue_agent.persistence.engine import get_engine
from ruixue_agent.persistence.repository import PgRepository
from ruixue_agent.rag.bm25 import Bm25Search
from ruixue_agent.rag.milvus_store import MilvusVectorStore
from ruixue_agent.rag.rerank import Reranker
from ruixue_agent.rag.retriever import Retriever
from ruixue_agent.rag.generate import Generator

store = MilvusVectorStore()
with Session(get_engine()) as sess:
    retriever = Retriever(
        store, PgRepository(sess),
        bm25=Bm25Search(sess),      # 混合检索
        reranker=Reranker(),        # 精排
    )
    gen = Generator(retriever)
    ans = gen.answer("地膜厚度的国家标准是多少?", k=4)
    print(ans.text)                 # 带引用的答案
    for h in ans.hits:              # 出处,供核实
        print(h.document_id, h.section_path)
```

过滤示例:`gen.answer("...", year_min=2022, source="标准规范")` — 前过滤在 Milvus 内部发生。

## 运维

```bash
docker compose ps                  # 看容器状态
docker compose logs -f milvus      # 看日志
docker compose down                # 停(数据保留在命名卷)
uv run pytest                      # 全量测试
uv run ruff check . && uv run ruff format .   # 代码检查 + 格式化
```

Milvus / 词频表 / 分词都是**派生数据**,丢了能重建;PostgreSQL 是资产,须备份。
